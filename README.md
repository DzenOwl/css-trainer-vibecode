# CSS-задачник для начинающих верстальщиков

Учебный сайт с задачами на отработку базовых CSS-селекторов. Каждый раздел —
это отдельная секция страницы с якорем для навигации.

## Разделы и количество задач

| Раздел | Селектор | Задач |
|---|---|---|
| 1. Контекстные селекторы | `main p`, `nav a`, `.card h3` и пр. | 10 |
| 2. Классы | `.btn`, `.note.warning`, `тег.класс` | 10 |
| 3. Псевдокласс :hover | `.btn:hover`, `tr:hover` | 10 |
| 4. Псевдокласс :visited | `a:visited` и ограничения браузеров | 10 |
| 5. Псевдокласс :first-child | `p:first-child`, `li:first-child` | 10 |
| 6. Псевдокласс :last-child | `p:last-child`, комбинированные приёмы | 10 |

**Итого: 60 задач.**

## Формат задачи

Каждая карточка содержит три панели:

- **Дано (HTML)** — разметку, к которой нужно написать стили;
- **Ваш CSS** — текстовое поле, куда пишется решение (кнопка «Применить»
  или Ctrl+Enter);
- **Результат** — предпросмотр: HTML задачи с применённым CSS пользователя
  рендерится в изолированном `<iframe>`.

Ниже панелей — **Цель**: что должно получиться после написания CSS.
Написанный код автоматически сохраняется в `localStorage` и восстанавливается
при следующем открытии страницы.

## Ограничение по свойствам

Во всех задачах достаточно «простых» CSS-свойств:
`color`, `background-color`, `font-size`, `font-weight`, `font-style`,
`font-family`, `text-decoration`, `border`, `border-radius`, `box-shadow`,
`padding`, `margin`, `cursor`, `list-style`, `transition`.

Сложные стили (`grid`, `flex-shrink`, `mask`, `transform` и т.п.) в задачах
не требуются.

## Как запустить

Сайт статический, но JS-файл подключается, поэтому открывайте его
через локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html      — страница с шестью разделами и 60 задачами
css/style.css   — оформление самого задачника
js/app.js       — редактор CSS и live-предпросмотр каждой задачи
tools/          — генератор index.html (tasks_data.py + generate.py)
```
