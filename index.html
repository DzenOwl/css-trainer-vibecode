1. Контекстные селекторы

Контекстный (потомковый) селектор выбирает элементы внутри другого элемента: main p, nav a, .card h3. Напишите CSS так, чтобы стиль применился только к нужным элементам.

Задача 1.1 — Все абзацы внутри main

Дано (HTML)

<main>
  <p>Первый</p>
  <p>Второй</p>
</main>
<p>Снаружи</p>

Ваш CSS

Результат

Цель: Сделайте все абзацы внутри main тёмно-синими, а абзац снаружи оставьте нетронутым.

Дано (HTML)

<nav>

  <a href="#">О нас</a>
</nav>
<p><a href="#">Ссылка в тексте</a></p>

Ваш CSS

Результат

Цель: Ссылки внутри nav сделайте зелёными и без подчёркивания; ссылка в тексте должна остаться синей.

Результат
